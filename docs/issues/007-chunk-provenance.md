# Issue 007: У чанков нет происхождения (раздел, страница), цитаты указывают только на «документ + номер чанка»

**Метки:** search-quality, citations, schema

## Проблема
`document_chunks` хранит только `chunk_index` и `content`. Из выдачи (`SearchSource`) нельзя узнать, в каком разделе или на какой странице находится фрагмент, а сам фрагмент может начинаться с середины раздела без заголовка и терять смысл («Он должен быть не менее 12 символов» — что «он»?). Для будущего LLM-синтеза с цитатами (`IMPROVEMENTS.md` п. 5) нужна внятная ссылка вида «Политика паролей → Требования, стр. 3». Чанкер (`chunking/chunk-text.ts`) уже разбирает markdown-структуру, но заголовки не сохраняет. `pdf-parse` умеет отдавать текст постранично через `pagerender`, сейчас это не используется.

## Предложение
- Миграция (после `IMPROVEMENTS.md` п. 4): в `document_chunks` добавить nullable-колонки `heading_path TEXT[]` и `page_start INT`, `page_end INT`. Колонка `embedding` и её размерность не затрагиваются.
- `chunkText` возвращает для каждого чанка актуальный путь заголовков (markdown `#`…`######`; для HTML/DOCX — после Issue 006). Для PDF страницы собираются через `pagerender`.
- В текст для эмбеддинга (но не в `content`, который показывается пользователю) добавлять префикс с заголовками: `"{документ} › {раздел}\n{content}"`. Это известный приём «contextual chunk headers». Эффект измерить на eval-наборе, оставить только если recall@5 не хуже.
- `GET /api/search` — добавить необязательные поля `headingPath` и `pageStart` в `SearchSource` (обратно совместимо); показать их во фронтенде в карточке источника.

## Критерии приёмки
- Юнит-тесты чанкера: путь заголовков корректен для вложенных разделов, code fence с `#` внутри не считается заголовком, frontmatter не ломает путь.
- Миграция применяется на существующей базе без потери данных; у старых чанков поля `NULL`, фронтенд это переносит.
- Контракт `/api/search` расширен только добавлением полей, фронтенд обновлён в том же PR.

## Риски
Префикс в эмбеддинге меняет векторы (нужна переиндексация, решение владельца). Нужно убедиться, что префикс укладывается в лимит токенов эмбеддера (Issue 001).
