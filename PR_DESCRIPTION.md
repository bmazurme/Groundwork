Статический анализ `apps/backend` и `apps/frontend` (конфигурация, контроллеры и сервисы документов/поиска, Dockerfile, провайдеры эмбеддингов, тесты фронтенда) и сверка с Issue 001–030 и `IMPROVEMENTS.md`. Код приложения **не менялся**; приложение, тесты и сборка не запускались (в снимке нет `node_modules`, `.git`, `init.md`, `ISSUES.md`).

1. **Открытые Issue.** Данных трекера в снимке нет, поэтому открытых Issue для работы нет. Файлы `docs/issues/001–030` — предложения прошлых раундов, не задачи трекера; реализовывать их без запроса владельца я не стал (большие, часть меняет схему и контракт).
2. **Новые предложения** (5, лимит соблюдён) — `docs/issues/031…035-*.md`, индекс `docs/issues/README.md` обновлён. Дубликаты исключены поиском по существующим Issue (Swagger/OpenAPI, пагинация, Vitest, ErrorBoundary, валидация env, кеш эмбеддингов в них не встречались).

## Предложения и обоснование

### 031 — Валидация конфигурации
- **Найдено:** `process.env.X ?? default` в 8 местах; `EMBEDDINGS_PROVIDER=ollma` молча выбирает ONNX, `REDIS_PORT=abc` → `NaN`, пустой `DATABASE_URL` → подключение по умолчанию.
- **Решение:** `loadConfig()` с типизированным `AppConfig`, падение на старте со списком всех ошибок, DI вместо чтения `process.env`; без новых зависимостей (`zod` — опционально). Нужна до добавления env реранкера/LLM/Langfuse.

### 032 — Пагинация и лимиты
- **Найдено:** `findAll()` и `getChunks()` без `LIMIT`; большой документ — тысячи чанков в одном ответе; `:id` не проверяется как UUID.
- **Решение:** keyset-курсор, `limit` с максимумом, серверные фильтры; обратная совместимость (массив + заголовок продолжения), `useInfiniteQuery` во фронтенде, `ParseUUIDPipe`.

### 033 — OpenAPI
- **Найдено:** контракт нигде не описан и не проверяется, типы фронтенда копируются вручную; правило «не ломай контракт» нечем обеспечить.
- **Решение:** `@nestjs/swagger`, закоммиченный `openapi.json`, CI-проверка расхождений; новая зависимость обоснована, `npm audit` — в PR реализации.

### 034 — Тесты фронтенда и ErrorBoundary
- **Найдено:** только Cypress; чистая логика (`highlight-terms`, `strip-html-comments`, клиент API) без тестов; исключение рендера Markdown/Mermaid в чужом документе роняет всё приложение.
- **Решение:** Vitest + Testing Library (dev-зависимости), `ErrorBoundary` вокруг контента документов.

### 035 — Кеш эмбеддингов запросов и таймауты
- **Найдено:** эмбеддинг запроса считается заново каждый раз в процессе API; нет таймаутов, лимита длины запроса и ограничения параллелизма.
- **Решение:** декоратор `CachingEmbeddingsProvider` (ключ включает модель), `SEARCH_TIMEOUT_MS`, лимит длины, семафор; по умолчанию поведение без изменений.
